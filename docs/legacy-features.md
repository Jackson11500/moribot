# 茉莉旧功能、使用权限与恢复条件

核查日期为 2026-11-24。核对了本机 Git 中可达的 118 个提交。主分支代码（`8887c8e`）有 55 个 NoneBot 匹配器，另一条历史分支（`origin/Lucky-Clover`，`a045c4b`）有 76 个，两边多数功能重合。以下按用户能触发的行为列出，等价写法放在同一行。命令按旧配置的空前缀书写，示例中的尖括号表示需要替换的参数。

**当前可用性。** Linux 上的 OpenQQ v0.5.0 已接收过真实消息，也曾通过一次单独授权的动作发出私聊文字。常驻 NoneBot2 入口只统计签名上报，返回空 HTTP 204，禁止 API 调用，未加载旧插件。下表的“可移植”均以接通受控的 OneBot 发送通道并迁移对应处理器为前提。群发言、发图、合并转发及改名片此次只核对了发行包的接口，没有在线执行。[接收入口](../receive_only/receiver.py) · [部署与验证记录](../.agents/skills/moribot-receive-only/references/deployment.md)

**权限读法。** “群”指普通群员可以触发。“群 · 某开关”还要求群配置表里已登记该群，并开启对应模块。“双端”表示旧处理器允许私聊和群聊，机器人仍需能在该会话发言。“超管”是 NoneBot 配置的超级用户，与 QQ 群管理员是两种角色。铜、铅、钛、钍是旧机器人的游戏资源。[群开关](../src/plugins/__toolbox.py) · [费用表](../src/plugins/user/databank.py) · [扣费逻辑](../src/plugins/user/utils.py)

| MC 订阅状态发生变化，每 5 分钟轮询 | 已订阅的私聊或群 | 无聊天指令，由定时器触发 | 主动发文字 | 只在上下线变化时向订阅会话推送。恢复还需调度器、订阅存储及主动发信能力。 |

历史源码可用 `git show a045c4b:src/plugins/user/__init__.py` 等形式查看。MC 订阅版见提交 `e97a970`，早期天气与问候见 `4132063`。建筑、区块和红包在历史配置中有条目，核查的匹配器中未找到对应的独立玩家命令。语音文件在资源目录中，但上列插件未发现向用户发语音的正式入口。旧项目声明的第三方插件包仅有依赖或加载配置，仓库内没有可核实的完整指令实现。

## 接回现有框架时的实际依赖

| 行为 | 现有框架可用的机制 | 本次判断依据与恢复条件 |
|---|---|---|
| 命令、普通消息、通知的分派 | NoneBot2 匹配器、OneBot v11 消息与通知事件 | 主分支大量使用旧的 `nonebot.adapters.cqhttp`、旧版事件参数及 Pydantic 配置。迁移时按功能加载所需处理器，显式使用群或私聊事件、读取命令参数，处理尚未登记的群。历史分支已有一部分 v11 写法可复用。 |
| 原会话文字、@、引用 | 私聊 `send_private_msg`、群聊 `send_group_msg`，OneBot v11 的 `text`、`at`、`reply` 消息段 | 私聊文字有真实回执。OpenQQ 实现群发送、群内 @ 和引用，引用需要有效的入站消息 ID。NoneBot 需要出站动作通道，现有 HTTP POST 上报及空 204 只负责接收。 |
| 素材图或制作图 | 两者都用 `image` 消息段，制作图先由 Pillow 渲染 | 可传图片字节（base64）或 OpenQQ 可读的 Linux 文件。旧 Windows 绝对路径不能在服务器使用。当前仓库有 `resources/ttf`，旧代码多指向 `resources/fonts`，主分支缺少多项指定底图、字库和外部图库。 |
| 群合并转发、跨群投递、改群名片 | `send_group_forward_msg` 的 `node`，定向 `send_group_msg`，以及 `set_group_card` | v0.5.0 发行包有对应实现。自定义节点与引用节点需分别适配，跨群依赖专用号可访问目标群，名片操作还受 QQ 权限约束。需分别实测。 |
| 注册、资源、签到、排行榜 | 用户档案、群设置、收费表，加上普通消息或制图 | 历史 CSV 可以提供迁移样本，早期汇总表和后期分用户目录格式不同。当前 systemd 接收服务使用 `ProtectSystem=strict`，实际写档、备份和制图需要指定可写位置，不能直接沿用旧插件目录。 |
| 定时推送与外部查询 | 独立调度、数据源及普通发送动作 | 定时器需要订阅目的地和可恢复的状态，天气占位、旧 MC 服务器及 Mindustry 数据源的业务可用性要分别验证。 |
